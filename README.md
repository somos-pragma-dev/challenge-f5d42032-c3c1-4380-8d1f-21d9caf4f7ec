# Desarrollo de una aplicación de gestión de tareas con React y TypeScript

La aplicación permitirá a los usuarios crear, editar y eliminar tareas. Cada tarea tendrá un título, una descripción y un estado (pendiente, en progreso, completado). Los usuarios podrán filtrar las tareas por estado y buscar tareas por título. La aplicación deberá ser escalable y mantener un buen rendimiento con un número creciente de tareas.
